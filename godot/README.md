# เมืองที่สร้างจากเสียง VR (ต้นแบบ Godot)

ต้นแบบเล็กของโหมด "บรรเลงตามโน้ต" จากเว็บ (index.html) ทำใน Godot เพื่อเล่นกับ SteamVR ผ่าน OpenXR โดยตรง ไม่ผ่านเบราว์เซอร์

มีอะไรบ้าง: ระนาดเอก 14 ลูกตรงหน้า, ไม้ตีในมือทั้งสองข้าง (ตีลงบนลูกจริง + สั่น), เสียงระนาด/ฆ้อง/ฉิ่งสังเคราะห์,
เส้นแสงนำทาง 14 เส้นแบบ Guitar Hero, ดวงแสงสีประจำวันวิ่งมาถึงลูกตรงจังหวะ, ครูเล่นโน้ตที่พลาดให้เบาๆ,
คอมโบ (ยิ่งตีติด เสียงครูยิ่งจาง), ป้าย "ตรงจังหวะ! / ดี / คอมโบ N", วงแหวน+เปลวแสงตอนตีโดน
ยังไม่มี: วิหาร, ฉากรุ่งอรุณ/เมือง, เลือกเพลง

## เปิด
1. ติดตั้ง Godot **4.3 ขึ้นไป** (Standard, ไม่ใช่ .NET) จาก https://godotengine.org/download
2. เปิด SteamVR ให้แว่นพร้อม (SteamVR ต้องเป็น OpenXR runtime)
3. เปิด Godot > Import > เลือกไฟล์ `godot/project.godot` > Import & Edit
4. กด ▶ (F5) ขวาบน ถ้ามีแว่นจะเข้า VR เลย ถ้าไม่มีจะเปิดหน้าต่างปกติ (คลิกลูกระนาด หรือกด 1–0 q w e r)

ครั้งแรก Godot จะ import ฟอนต์และสร้างไฟล์ใน `.godot/` (ไม่ต้อง commit)

## ถ้ามีปัญหา
ดูแท็บ **Output** ด้านล่างของ Godot บรรทัดแรกจะบอกว่า `VR (OpenXR)` หรือ `desktop (no headset found)`
ถ้ามีข้อความสีแดง แคปส่งมาได้เลย
